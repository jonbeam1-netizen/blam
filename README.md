# B.L.A.M. — Blast like a maniac!

A browser light-gun arcade shooter made of mini-games, in the spirit of the classic
arcade shooting galleries. Pixel / voxel / dither look, plays with a mouse on PC or
by tapping on a phone. Online versus with a join code (peer-to-peer, no server).

Play it: https://jonbeam1-netizen.github.io/blam/

- **PLAY**: pick a course (Beginner / Advanced / Very Hard / Insane), four stages, hearts for lives.
- **VERSUS**: host gets a code like `BLAM-7K2F`, a friend joins with it.
- **FREE PLAY**: any stage at any tier. **Key 4** cycles gun skins.

Build stamp shows on the title screen. Static files only, no build step.
